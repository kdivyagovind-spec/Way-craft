# WayCraft — Craft Your Journey, Your Way ✈️

A travel-planning website designed to help users explore destinations, organize trip preferences, and review sample itineraries and estimated budgets.

## Overview

WayCraft is a travel-planning website that brings destination exploration, trip planning, itinerary previews, and budget estimation together in one place.

The project presents a structured travel-planning experience, allowing users to explore destinations, consider their travel preferences, and view sample trip plans.

## Features

- **Explore Destinations** — Discover destinations through destination cards.
- **Plan Your Trip** — View a trip-planning form with destination, travel dates, interests, preferences, and budget.
- **Journey Itinerary** — Explore a sample travel itinerary.
- **Expense Estimation** — Review estimated trip expenses, including accommodation, food, travel, activities, and additional costs.
- **Plan Comparison** — Compare two sample travel plans.
- **Final Plan Summary** — View a summarized travel plan.
- **Multi-Section Layout** — Navigate through different sections of the travel-planning experience.

## Getting Started

### Prerequisites

- A web browser
- A code editor such as Visual Studio Code

### Run Locally

1. Clone the repository:

   ```bash
   git clone YOUR_REPOSITORY_URL
   ```

2. Navigate to the project folder:

   ```bash
   cd WayCraft
   ```

3. Open `index.html` in your browser.

Alternatively, use the Live Server extension in Visual Studio Code to launch the website.
